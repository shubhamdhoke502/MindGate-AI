# Contributing to MindGate AI

Thank you for your interest in contributing to MindGate AI!

## How to Contribute

1. Check existing Issues and Discussions before starting.
2. Open an Issue to discuss major changes or new features.
3. Fork the repository and create a separate branch for your changes.
4. Make your changes and test them locally.
5. Submit a Pull Request explaining what changed and why.

## Code Guidelines

- Keep changes focused and easy to review.
- Follow the existing project structure and coding style.
- Do not commit API keys, passwords, private documents, virtual environments, or local database files.
- Update documentation when necessary.

## Bug Reports

Use GitHub Issues to report reproducible bugs. Include steps to reproduce the problem and relevant error messages.

## Feature Requests

Use GitHub Issues or Discussions to describe the proposed feature and its use case.

Thank you for helping improve MindGate AI!
