# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in MindGate AI, please report it privately to the repository owner before making it public.

Include the following details:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and affected components.

Please do not include real API keys, passwords, or private documents in public issues.

## Supported Versions

Security fixes are currently focused on the latest version of MindGate AI.

## Response

I will review reports and work to address valid security issues as time and resources permit.
